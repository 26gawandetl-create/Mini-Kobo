
# 🍜 MINI KOBO

## About the Project
Mini Kobo is a ramen ordering website designed to provide users with a simple and convenient food ordering experience.

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Features
- Attractive homepage
- Ramen food menu
- Add to Cart functionality
- Increase and decrease item quantity
- Remove items from cart
- Automatic price calculation
- Checkout form
- Order confirmation page
